# 💼 Portafolio Web

¡Bienvenido a mi portafolio web! 

Este proyecto presenta mi perfil académico y profesional, incluyendo información sobre mí, mi formación, habilidades, proyectos y medios de contacto.

El portafolio fue desarrollado a partir de una plantilla de **Stylish Portfolio de Start Bootstrap**, adaptándola visualmente y modificando su contenido para crear una presentación personal.

## ✨ Características

- Página de inicio con presentación personal.
- Sección "Sobre mí".
- Sección de formación académica.
- Sección de habilidades.
- Presentación de proyectos realizados.
- Sección de contacto.
- Diseño adaptable a dispositivos móviles.
- Personalización de colores, textos e imágenes.
- Uso de iconos para mejorar la presentación visual.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap
- JavaScript
- Font Awesome
- Google Fonts
- Start Bootstrap - Stylish Portfolio
